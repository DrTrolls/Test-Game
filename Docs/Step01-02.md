# Steps 1-2: Scene + Player Setup

This document explains how to complete and verify Steps 1-2 of the vertical slice in Unity. Follow the checklist in order.

## Step 1 — Project structure and GameScene setup
1. Create folders under `Assets`: `Scenes`, `Scripts/Player`, `Scripts/Camera`, `Sprites/Placeholders`, and `Materials` (optional for tinting placeholder sprites).
2. Create a new **Scene** named `GameScene` and save it in `Assets/Scenes`.
3. Configure **Sorting Layers** (Edit → Project Settings → Tags and Layers):
   - `Floor`
   - `Pickups`
   - `Player`
   - `Enemies`
   - `Projectiles`
   - `UI` (UI defaults to `Default`/`UI` canvas layer can be left alone)
4. Create placeholder sprites (Sprite → Square/Circle) in `Assets/Sprites/Placeholders/`:
   - Floor tile (large square, dark gray, sorting layer `Floor`).
   - Player body (bright neon square), sorting layer `Player`.
   - Optional: cursor/indicator sprite for testing.
5. Create a **Main Camera** (or use the default):
   - Projection: **Orthographic**.
   - Set `Size` ~6 as a starting value.
   - Attach `CameraFollow2D` (from `Assets/Scripts/Camera`).
   - Assign the `Target` to the Player object (after creating it in Step 2).
   - Offset suggestion: `(0, 8, -8)`; Tilt Angle: `20` degrees.
6. Add a floor quad/grid: place a large tile at `y = 0`, set sorting layer `Floor`. Duplicate/scale to cover play area as needed.

**How to test Step 1**
- Enter Play Mode after assigning the player (Step 2). The camera should sit at an angled top-down view, following the target smoothly and keeping the floor visible.

## Step 2 — Player movement and health
1. In `Assets/Scripts/Player/`, create and attach `PlayerController` and `PlayerHealth` (scripts provided in this repo).
2. Create an empty GameObject named **Player** at `(0, 0, 0)`.
   - Add a **SpriteRenderer** using the neon placeholder sprite, sorting layer `Player`.
   - Add a **Rigidbody2D**: Body Type `Dynamic`, Freeze Rotation `Z`, Collision Detection `Continuous`.
   - Add a **CapsuleCollider2D** (or BoxCollider2D) sized around the sprite.
   - Add the `PlayerController` and `PlayerHealth` components.
3. Configure `PlayerController` values (baseline):
   - Move Speed: `7`
   - Acceleration: `18`
   - Deceleration: `22`
   - Input Dead Zone: `0.1`
   - Max Speed: `8`
4. Configure `PlayerHealth` values:
   - Max Health: `100`
   - Current Health initializes to max; `InvulnerabilityTime` can be `0` for now.
5. On the Main Camera, set `CameraFollow2D.Target` to the Player transform.

**How to test Step 2**
- Enter Play Mode. Use **WASD** or arrow keys; the player should accelerate smoothly and decelerate when releasing keys.
- Ensure the camera follows the player with the set offset/tilt.
- (Optional) In the Inspector, call `PlayerHealth.TakeDamage(10)` via the context menu to see health values decrease, and `ResetHealth` to restore.
