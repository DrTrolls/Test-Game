# Build Plan

This checklist covers the vertical slice for the cyberpunk fantasy survivor-style prototype. Each step lists goals and includes testing notes. Completed steps are checked off.

## Checklist
- [x] Step 1: Project structure + GameScene core setup
- [x] Step 2: Player movement and health
- [ ] Step 3: Enemy spawner and basic AI
- [ ] Step 4: XP orbs, pickup and leveling
- [ ] Step 5: Level-up choice UI (pause + three choices)
- [ ] Step 6: Weapon system (auto-fire, four starter weapons)
- [ ] Step 7: Passive upgrades (global modifiers)
- [ ] Step 8: Evolutions / synergies (two examples)
- [ ] Step 9: Difficulty scaling over time
- [ ] Step 10: 20-minute boss and victory flow
- [ ] Step 11: Credits + meta progression stub

## Assumptions
- Unity 2021 LTS or newer 2D project template.
- Input uses default old Input Manager axes (Horizontal/Vertical) plus WASD; can swap to the new Input System if desired.
- Placeholder sprites are simple colored shapes made in Unity (Sprite > Square/Circle) with basic sorting layers.
- Camera uses an orthographic projection with a slight X rotation for faux depth; lighting/post-processing optional.

## Testing expectations
Each step includes a "How to test" subsection in the implementation instructions stored alongside the relevant scripts.
